# TableManners

A virtual tabletop (VTT) for D&D.

## Features

* **Grid Maps** — Create and interact with grid-based maps.
* **Token-Based Gameplay** — Add and move character and creature tokens on the map.
* **Drawing Tools** — Draw directly on the grid map for notes, markings, and other gameplay purposes.
* **Game State Saving** — Save and restore game states for ongoing campaigns.
* **D&D 5e SRD Integration** — Quickly search the D&D 5e database for game information.
* **User Accounts** — Create accounts and access saved game states.
* **Character Tokens** — Create character tokens that can be accessed and used by the DM.

## Tech Stack

* JavaScript
* React
* Node.js
* Express
* PostgreSQL
* HTML/CSS
